# Audit dan Hasil Perbaikan

Tanggal verifikasi: 15 November 2026.

## P0 — diselesaikan

- Data biaya yang sebelumnya terduplikasi di JSON dan JavaScript disatukan ke `assets/content.json`.
- Total KB Rp6.525.000, TK A Rp7.005.000, TK B Rp6.555.000 dan potongan Rp750.000/Rp500.000/Rp250.000/Rp0 diuji otomatis.
- Dibuat halaman terpisah `bunayya-i.html` dan `bunayya-ii.html`.
- Tiga PDF dibuat ulang dengan teks yang dapat dipilih, logo resmi, tabel, kebijakan, dan metadata.
- Kalkulator menjelaskan bahwa SPP/Infaq bulanan hanya dihitung satu kali dalam jumlah awal.

## P1 — diselesaikan

- Redesign penuh Premium Modern Islamic School: biru BUNAYYA, ivory, emas, tipografi editorial, komposisi asimetris, dan detail gerak tertahan.
- Hero carousel dengan pause, gallery rail/masonry, kategori, lightbox fullscreen, tombol/keyboard, dan empty-state foto yang jujur.
- Bahasa Indonesia–English diterapkan pada navigasi, konten utama, kalkulator, dan label unduhan. Teks kebijakan Indonesia dipertahankan sebagai sumber otoritatif.
- Menu mobile, fokus terlihat, skip link, reduced-motion fallback, dan pencegahan horizontal overflow.

## P2 — diselesaikan

- Metadata dasar SEO, robots, clean URLs, security headers, GitHub Pages workflow, dan Vercel config.
- Pengujian data Node dan matriks browser Playwright di 1440, 768, 390, dan 360 px.

## Batas verifikasi sumber

Brief menyebut lima gambar brosur asli sebagai sumber otoritatif, tetapi gambar tersebut tidak ada di ZIP maupun repository GitHub. Nilai dan kebijakan dipertahankan dari transkripsi paket v3; klaim reproduksi baris-per-baris terhadap gambar asli tidak dibuat.
